# References and implementation scope

[Deep Differentiable Logic Gate Networks](https://arxiv.org/abs/2210.08277) — Felix Petersen, Christian Borgelt, Hilde Kuehne, and Oliver Deussen, NeurIPS 2022.

[Convolutional Differentiable Logic Gate Networks](https://arxiv.org/abs/2411.04732) — Felix Petersen, Hilde Kuehne, Christian Borgelt, Julian Welzel, and Stefano Ermon, NeurIPS 2024.

This repository implements the referenced method in PyTorch. It is not the original authors' official implementation, and the architecture formulation is not claimed as a new method by this repository. Local training/evaluation code, experiment configuration, and result packaging should be distinguished from the published method.

The original DLGN project is [difflogic](https://github.com/Felix-Petersen/difflogic). Its optimized implementation is a reference, not evidence that this repository reproduces its performance.
